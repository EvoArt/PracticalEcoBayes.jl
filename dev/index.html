PracticalEcoBayes.jl

Gibbs kernels for ecological models, for the Gibbs sampler of PracticalBayes.jl. Each kernel draws one block of a model from its exact full conditional, so discrete latent states and logistic regressions need no gradients and mix well.

kernelblockmodel
PolyaGammaLogitlogistic-regression coefficientsoccupancy, detection, presence/absence
OccupancyStateslatent presence per sitesingle-species occupancy
NMixtureAbundancelatent abundance per sitebinomial N-mixture
IsingStatesBool states on a graphautologistic (spatial) occupancy
PottsLabelslabels 1:q on a graphspatial clustering

Every kernel takes a function of the current ModelConditional that returns what it needs (probabilities, designs, data), so it fits any model layout.

A single-species occupancy model

using PracticalBayes, PracticalEcoBayes, Distributions, Random
using LogExpFunctions: logistic

# single-species occupancy: y is sites × visits (missing = no visit)
rng = MersenneTwister(42)
ztrue = rand(rng, Bernoulli(0.6), 12)
y = Union{Missing,Int}[rand(rng, Bernoulli(ztrue[i] * 0.7)) for i in eachindex(ztrue), _ in 1:3]
y[2, 3] = missing

@model function occupancy(y)
    β ~ Normal(0, 2.5)                     # occupancy log-odds
    α ~ Normal(0, 2.5)                     # detection log-odds
    z = Vector{Bool}(undef, size(y, 1))
    for i in axes(y, 1)
        z[i] ~ Bernoulli(logistic(β))
        for j in axes(y, 2)
            ismissing(y[i, j]) || (y[i, j] ~ Bernoulli(z[i] * logistic(α)))
        end
    end
end

visits = [(i, j) for i in axes(y, 1), j in axes(y, 2) if !ismissing(y[i, j])]
spl = Gibbs(
    :z => OccupancyStates(c -> (fill(logistic(c.values.β), size(y, 1)),
                                fill(logistic(c.values.α), size(y)...), y), :z),
    :β => PolyaGammaLogit(c -> (ones(size(y, 1), 1), c.values.z), :β),
    :α => PolyaGammaLogit(:α) do c
        v = [(i, j) for (i, j) in visits if c.values.z[i]]   # visits to occupied sites
        (ones(length(v), 1), [y[i, j] for (i, j) in v])
    end)
chn = sample(rng, occupancy(y), spl, 2000; progress=false)

Markov random fields

PottsLabels and IsingStates sweep a neighbour graph built with grid_neighbours, distance_neighbours or Neighbours(A). Their normalising constants are intractable, so the interaction strength is estimated with the pseudo-likelihood (potts_pseudologlik, autologistic_pseudologlik), for example in a NUTS block via @addlogprob!.

For multispecies occupancy with species interactions, see MultispeciesOccupancy.jl.

API reference

PracticalEcoBayes.PracticalEcoBayes — Module
PracticalEcoBayes

Gibbs kernels for ecological models, to plug into PracticalBayes's Gibbs sampler:

  • PolyaGammaLogit: exact draws of logistic-regression coefficients by Pólya–Gamma augmentation (occupancy, detection, presence/absence models); rand_polyagamma draws the augmentation variables themselves.
  • OccupancyStates, NMixtureAbundance: the latent presence and abundance of hierarchical detection models.
  • PottsLabels, IsingStates: Markov random fields on a neighbour graph (Neighbours, grid_neighbours, distance_neighbours), for spatial clustering and autologistic occupancy, with pseudo-likelihoods potts_pseudologlik and autologistic_pseudologlik for the interaction strength.

Each kernel takes a function of the current ModelConditional that returns the quantities it needs, so it works with any model layout.

PracticalEcoBayes.IsingStates — Type
IsingStates(data, name, neighbours)

A Gibbs kernel for Bool states name of an Ising (autologistic) model on neighbours:

p(z) ∝ exp(Σᵢ hᵢ zᵢ + J Σ_{i~j} w_ij zᵢ zⱼ)

so that zᵢ given its neighbours is Bernoulli(logistic(hᵢ + J Σⱼ w_ij zⱼ)). data(c) returns (h, J): the node log-odds and the interaction strength. For autologistic occupancy, h is the occupancy log-odds plus the detection evidence log P(y | z=1) - log P(y | z=0) (Inf where a species was detected). One call sweeps every node once in random order.

source
PracticalEcoBayes.NMixtureAbundance — Type
NMixtureAbundance(data, name; K=nothing)

A Gibbs kernel for the latent abundances name (one Int per site) of a binomial N-mixture model (Royle 2004):

N[i] ~ Poisson(λ[i]),   y[i, j] ~ Binomial(N[i], p[i, j])

data(c) returns (λ, p, y) (sites; sites × visits; missing for no visit). Each N[i] is drawn exactly from its conditional on max(y[i, :]):K. K defaults to a bound well into the upper tail of the conditional.

PracticalEcoBayes.Neighbours — Type
Neighbours(adjacency; weights=nothing)

A neighbour graph: adjacency[i] lists the neighbours of node i (symmetric: j ∈ adjacency[i] exactly when i ∈ adjacency[j]), with optional edge weights weights[i] in the same order. Build one from a grid, coordinates or a matrix: grid_neighbours, distance_neighbours, Neighbours(A::AbstractMatrix).

Neighbours(A): from a symmetric adjacency (or weight) matrix; nonzero entries are edges.

PracticalEcoBayes.OccupancyStates — Type
OccupancyStates(data, name)

A Gibbs kernel for the latent occupancy states name (one Bool per site) of a single-species occupancy model (MacKenzie et al. 2002):

z[i] ~ Bernoulli(ψ[i]),   y[i, j] ~ Bernoulli(z[i] * p[i, j])

data(c) returns (ψ, p, y) for the current state: occupancy probabilities (one per site), detection probabilities and detections (sites × visits; missing for a visit that did not happen). A site with a detection is occupied; otherwise

P(z = 1 | y) = ψ ∏(1 - p) / (ψ ∏(1 - p) + 1 - ψ).
source
PracticalEcoBayes.PolyaGammaLogit — Type
PolyaGammaLogit(data, name; prior_mean=0, prior_sd=2.5)

A Gibbs kernel that draws the coefficient vector name of a logistic (binomial) regression exactly, by Pólya–Gamma data augmentation:

y[i] ~ Binomial(n[i], logistic(X[i, :]'β + offset[i])),   β ~ Normal(prior_mean, prior_sd)

data(c) receives PracticalBayes' ModelConditional and returns (X, y), (X, y, n) or (X, y, n, offset) for the current state, so the rows can depend on other variables (for detection given occupancy, only the visits to occupied sites). n defaults to 1 (Bernoulli). The model's prior on name should match prior_mean and prior_sd (numbers or vectors).

pk = PolyaGammaLogit(:α) do c
    occupied = c.values.z[site_of_visit]
    (Xdet[occupied, :], ydet[occupied])
end
spl = Gibbs(:α => pk, :z => OccupancyStates(...), :β => NUTS())

PracticalEcoBayes.PottsLabels — Type
PottsLabels(data, name, neighbours; q)

A Gibbs kernel for the labels name (one Int in 1:q per node) of a Potts model on neighbours:

p(x) ∝ exp(Σᵢ h[i, xᵢ] + β Σ_{i~j} w_ij [xᵢ = xⱼ])

data(c) returns (β, h) for the current state: the interaction strength and an n × q matrix of log-weights for each node and label (the data likelihood and any label-specific prior), or nothing for none. One call sweeps every node once, in random order, drawing each label from its exact conditional. A two-label Potts model is the Ising model; for presence/absence states use IsingStates.

Pseudo-log-likelihood of Bool states z under the autologistic model with node log-odds η (a number or one per node) and interaction J. Differentiable in η and J.

PracticalEcoBayes.polyagamma_logit_draw — Method
polyagamma_logit_draw([rng], X, y, β; n=1, offset=0, prior_mean=0, prior_sd=2.5)

One Pólya–Gamma Gibbs update of logistic-regression coefficients: given the current β, draw the augmentation variables and return a new β from its exact Gaussian conditional, for y[i] ~ Binomial(n[i], logistic(X[i, :]'β + offset[i])) and independent Normal(prior_mean, prior_sd) priors. The engine of PolyaGammaLogit, for kernels that update several regressions at once.

source
PracticalEcoBayes.potts_pseudologlik — Method
potts_pseudologlik(x, β, neighbours; h=nothing, q=maximum(x))

Besag's pseudo-log-likelihood of Potts labels x: the sum over nodes of each label's log conditional probability given its neighbours. Differentiable in β and h, so it can stand in for the intractable likelihood when estimating the interaction strength (for example in a NUTS block with @addlogprob!).

source
PracticalEcoBayes.rand_polyagamma — Method
rand_polyagamma([rng], b::Integer, c::Real)

One draw from the Pólya–Gamma distribution PG(b, c), the latent variable of the Polson–Scott–Windle data augmentation for logistic models. Its mean is b / (2c) * tanh(c / 2) (b / 4 at c = 0).
